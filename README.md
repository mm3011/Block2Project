The purpose of this repository is to show off a couple of cool projects I challenged myself with over the past summer to be able to learn some new languages and computer science topics. 

The projects that are currently within this repo are:

- Static Malware Analysis Tool - A simple program written in Rust that returns a secure filehash of any program to be cross-referenced with virustotal to check for malicious content
- ValPUUIDGrabber - A simple API connection challenge that grabs the PUUID of a Riot account given an NA Riot ID.
